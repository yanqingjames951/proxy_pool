# Proxy Pool

A high-performance Proxy Pool with a modern Vue 3 Dashboard and robust Python backend.

## ✨ Features

- **Modern UI**: Built with Vue 3, Vite, and Ant Design Vue.
- **Internationalization**: Full English and Chinese (Simplified) support.
- **High Performance**: Redis-based storage and async Python schedulers.
- **Docker Ready**: One-command deployment with Docker Compose.
- **Developer Friendly**: Comprehensive API documentation and integration examples.

##  Deployment

```bash
# Start services
docker-compose up -d --build
```
